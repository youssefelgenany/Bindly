# Login Background Image

Please place your login background image here and name it `login-background.jpg`.

**Supported formats:**
- JPG/JPEG
- PNG
- WebP

**Recommended dimensions:**
- Minimum: 1920x1080 pixels
- Aspect ratio: 16:9 or similar

**File location:**
`frontend/public/assets/images/login-background.jpg`

The image will be displayed on the right side of the login page with a dark blue overlay.
